# Marbar · Web

Web de una sola página para **Marbar** (Pg. de la Bonanova, 77 · Sarrià-Sant Gervasi, Barcelona).

Abre `index.html` en el navegador; no necesita build ni dependencias.

## Qué incluye
- Hero animado con valoración (4,9 ★ · 1.301 reseñas) y precio medio.
- Indicador "Abierto / Cerrado" en tiempo real (hora de Barcelona).
- Carta interactiva con categorías, filtros (vegetariano, sin gluten, favoritos) y calculadora "Tu mesa" con precio por persona.
- Carrusel de reseñas con barras de valoración.
- Formulario de reserva (día, hora, comensales) que envía la solicitud por WhatsApp al 673 65 07 74.
- Horario, mapa, cómo llegar, llamar y compartir.

## Antes de publicar
Los platos, precios, reseñas y el horario de apertura (13:00) son **orientativos**. Edita los datos reales en `script.js`:
`MENU`, `REVIEWS` y `HOURS`.
